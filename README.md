# 🇧🇷 Português

Um projeto desenvolvido em **Java** para registrar, listar e calcular despesas pessoais por meio de uma interface de console.

O objetivo foi colocar em prática os fundamentos da linguagem, trabalhando com métodos, estruturas de repetição, condicionais, listas dinâmicas e validação de entradas.

## 🚀 Funcionalidades

- **Registrar despesas:** adicionar uma despesa com nome e valor.
- **Listar despesas:** visualizar todas as despesas cadastradas.
- **Calcular total:** exibir a soma de todas as despesas registradas.
- **Limpar registros:** apagar todas as despesas mediante confirmação.
- **Validação de entradas:** tratar entradas inválidas e impedir valores menores ou iguais a zero.
- **Menu interativo:** navegar pelas opções até decidir encerrar o programa.

## 🛠️ Tecnologias utilizadas

- **Java** — linguagem de programação.
- **ArrayList** — armazenamento dinâmico dos nomes e valores das despesas.
- **Scanner** — leitura das entradas fornecidas pelo usuário.

## 📚 Conceitos praticados

- Variáveis e tipos de dados.
- Métodos e organização do código.
- Estruturas condicionais com `switch`.
- Laços de repetição com `for`, `while` e `do-while`.
- Manipulação de listas com `ArrayList`.
- Tratamento de exceções com `try-catch`.
- Validação de dados fornecidos pelo usuário.
- Entrada e saída de dados no console.
- Formatação de valores monetários.

## ▶️ Como executar

**Pré-requisitos:** Java JDK instalado e configurado.

O usuário pode registrar despesas, consultar os registros, verificar o total gasto e limpar a lista quando necessário.

## ⚠️ Limitações atuais

- Os dados são armazenados apenas durante a execução do programa.
- Ao encerrar o programa, as despesas registradas são perdidas.
- O projeto funciona exclusivamente pelo console.
- O armazenamento utiliza listas separadas para os nomes e valores.

Mais do que praticar comandos isolados, o objetivo foi aprender a combinar diferentes recursos da linguagem para resolver um problema prático e organizar melhor o código.

# 🇺🇸 English

A **Java** project for recording, listing, and calculating personal expenses through a console-based interface.

The goal was to practice Java fundamentals, including methods, loops, conditional statements, dynamic lists, and input validation.

## 🚀 Features

- **Register expenses:** add an expense with a name and amount.
- **List expenses:** display all registered expenses.
- **Calculate total:** show the sum of all registered expenses.
- **Clear records:** delete all expenses after confirmation.
- **Input validation:** handle invalid input and reject amounts less than or equal to zero.
- **Interactive menu:** navigate through the available options until exiting the program.

## 🛠️ Technologies

- **Java** — programming language.
- **ArrayList** — dynamically stores expense names and amounts.
- **Scanner** — reads user input from the console.

## 📚 Concepts practiced

- Variables and data types.
- Methods and code organization.
- Conditional statements using `switch`.
- Loops using `for`, `while`, and `do-while`.
- List manipulation with `ArrayList`.
- Exception handling with `try-catch`.
- User input validation.
- Console input and output.
- Currency formatting.

## ▶️ How to run

**Prerequisites:** Java JDK installed and configured.

1. Clone this repository:

   ```bash

   ```

2. Navigate to the project folder:

   ```bash
   cd PROJECT_FOLDER_NAME
   ```

3. Compile the program:

   ```bash

   ```

4. Run it:

   ```bash

   ```

## 💻 Usage example

```text

==== Hello Noah ====
```

Users can register expenses, view their records, check the total amount spent, and clear the list when needed.

## ⚠️ Current limitations
